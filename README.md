# client-s_banking_operations_widget

## Цель проекта:

Учебный проект - разработка виджета банковских операций клиента. 
Приложение фильтрует, сортирует и накладывает маску на операции клиента.

## Установка и запуск приложения:

1. Клонируйте репозиторий:
```
git clone https://github.com/PavelOleynikov/client-s_banking_operations_widget.git
```
cd client-s-banking-operations-widget

2. Установите зависимости с помощью Poetry:
```
poetry install
```
3. Активируйте виртуальное окружение:
```
poetry shell
```
4. Запустите приложение:
```
python main.py
```
## Использование:

3. Используйте функции вывода списка словарей по ключу 
и сортировки списка словарей по дате

## Как запустить тесты:
    1. Сохраните тесты в файле 
    2. Установите pytest, если не установлен:
       poetry add pytest
    3. Запустите тесты:
       например: pytest test_mask_account_card.py -v

## Функции в проекте:
    1. get_mask_card_number
    """функция маскировки номера банковской карты"""
    2. get_mask_account
    """Функция маскировки номера банковского счета"""
    3. filter_by_state
    """функция вывода списка словарей по ключу state"""
    4. sort_by_date
    """функция сортировки списка словарей по дате"""
    5. mask_account_card
    """функция маскировки номера банковской карты или счета"""
    6. get_date
    """функция извлечения даты"""
    7. filter_by_currency
    """функция фильтра транзакций по валюте операции"""
    8. transaction_descriptions
    """функция описания каждой операции"""
    9. card_number_generator
    """генератор номеров банковских карт"""
    10. log(filename)
    """Декоратор для логирования выполнения функции.
    Если задан filename, лог записывается в файл, иначе 
    выводится в консоль"""
    11. get_data_operations
    """получает данные о финансовых транзакциях 
    из json файла"""
    12. convert_currency
    """функция возвращает сумму транзакции в рублях, 
    иначе конвертирует в рубли через внешний API"""
    13. read_csv
    """Чтение csv файла и возврат списка словарей"""
    14. read_xlsx
    """Чтение xlsx файла и возврат списка словарей"""
    15. process_bank_search
    """функция возвращает список операций 
    по заданной строке поиска"""
    16. process_bank_operations
    """функция возвращает словарь с количеством операций
    в каждой категории"""
    17. main
    """основная функция, которая запускает проект
    и отвечает за логику программы"""
